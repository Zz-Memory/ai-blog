# 项目目录清单

本文档用于说明本项目在完成开发时，建议创建的核心文件夹位置及其作用。目录规划以 Next.js 页面路由、通用组件、业务逻辑、数据库、类型定义和静态资源为主。

## 1. 根目录核心文件夹

### `app/`
- **作用**：Next.js 路由目录，承载页面、布局、错误页、加载页和 API 接口。
- **适用内容**：
  - 公共访客页
  - 访客个人中心
  - 博主后台
  - 接口路由 `route.ts`

### `components/`
- **作用**：存放可复用的 UI 组件和业务组件。
- **适用内容**：
  - 基础 UI 组件
  - 页面布局组件
  - 博客文章组件
  - 评论组件
  - AI 编辑器组件
  - 个人中心组件
  - 后台管理组件
  - 身份认证弹窗组件

### `lib/`
- **作用**：存放业务逻辑、工具函数、数据库封装和第三方服务调用。
- **适用内容**：
  - 数据库访问封装
  - 鉴权逻辑
  - AI 调用封装
  - Markdown 处理
  - 上传处理
  - 通知处理
  - 通用工具函数

### `types/`
- **作用**：存放 TypeScript 类型定义。
- **适用内容**：
  - 用户类型
  - 文章类型
  - 评论类型
  - 通知类型
  - AI 类型
  - 通用类型

### `prisma/`
- **作用**：存放数据库模型、迁移文件和种子数据。
- **适用内容**：
  - `schema.prisma`
  - `migrations/`
  - `seed.ts`
  - `seeds/`

### `public/`
- **作用**：存放静态资源。
- **适用内容**：
  - 网站图标
  - 默认头像
  - 封面图
  - 静态图片
  - 字体资源

### `docs/`
- **作用**：存放项目文档。
- **适用内容**：
  - 架构说明
  - 数据库设计说明
  - 页面设计说明
  - 开发规范
  - 接口说明

## 2. 推荐的路由与页面组织

### `app/(public)/`
- **作用**：公共访客页面分组。
- **示例页面**：
  - 首页
  - 文章详情页
  - 标签页
  - 搜索页

### `app/(visitor)/account/`
- **作用**：访客端个人中心页面分组。
- **示例页面**：
  - 浏览记录
  - 我的收藏
  - 我的评论
  - 我的点赞
  - 消息通知
  - 账号设置

### `app/(blogger)/dashboard/`
- **作用**：博主端后台页面分组。
- **示例页面**：
  - 数据概览
  - 文章管理
  - 评论审核
  - 发送消息
  - 用户管理
  - AI 编辑器

### `app/api/`
- **作用**：后端接口目录。
- **示例接口**：
  - 文章增删改查
  - 评论审核
  - 点赞 / 收藏
  - AI 生成
  - 文件上传

> 说明：本项目的身份认证界面采用**弹出式面板**实现，不作为独立页面路由处理，因此一般不创建 `app/(auth)/` 这类页面分组。

## 3. 推荐的组件目录结构

### `components/ui/`
- **作用**：最基础的通用 UI 组件。
- **示例**：按钮、输入框、弹窗、标签、分页、骨架屏。

### `components/layout/`
- **作用**：页面级布局组件。
- **示例**：顶部导航、侧边栏、页脚、容器布局。

### `components/blog/`
- **作用**：文章相关组件。
- **示例**：文章卡片、文章列表、正文渲染、目录导航。

### `components/editor/`
- **作用**：AI 博客编辑器相关组件。
- **示例**：标题输入、Markdown 工具栏、预览区、状态栏。

### `components/ai/`
- **作用**：AI 能力相关组件。
- **示例**：AI 问答面板、悬浮按钮、生成标题模块。

### `components/auth/`
- **作用**：身份认证相关的弹出式界面组件。
- **适用内容**：
  - 登录弹窗
  - 注册弹窗
  - 找回密码弹窗
  - 重置密码弹窗
  - 验证码输入组件
  - 密码显示切换组件

### `components/visitor/`
- **作用**：访客个人中心组件。
- **示例**：历史记录、收藏夹、点赞列表、通知列表、账号设置表单。

### `components/blogger/`
- **作用**：博主后台组件。
- **示例**：数据概览、文章表格、评论审核、用户管理、消息发送。

### `components/shared/`
- **作用**：跨模块复用的小组件。
- **示例**：搜索框、确认弹窗、状态标签、分隔线、通用卡片。

## 4. 推荐的辅助目录结构

### `hooks/`
- **作用**：存放自定义 React Hooks。
- **示例**：
  - `useAuth`
  - `usePagination`
  - `useEditor`
  - `useNotification`
  - `useAiChat`

### `stores/`
- **作用**：存放全局状态管理。
- **示例**：
  - 用户状态
  - UI 状态
  - 编辑器状态
  - 主题状态

### `middleware.ts`
- **作用**：项目根目录的访问控制入口。
- **适用内容**：
  - 登录拦截
  - 角色权限控制
  - 页面访问重定向

## 5. 当前项目建议优先创建的目录

如果是为了尽快完成项目，建议优先补齐以下目录：

1. `app/`
2. `components/`
3. `lib/`
4. `types/`
5. `prisma/`
6. `public/`
7. `docs/`

## 6. 目录职责总览

- **页面与路由**：`app/`
- **可复用组件**：`components/`
- **业务逻辑与工具**：`lib/`
- **类型定义**：`types/`
- **数据库与种子数据**：`prisma/`
- **静态资源**：`public/`
- **项目文档**：`docs/`

## 7. 说明

本清单用于项目实现阶段的目录规划参考。后续如果页面、接口或数据库模型发生调整，可以继续在本文件中补充更细的子目录说明。
