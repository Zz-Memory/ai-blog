摘    要

随着数字化内容传播方式的不断演进，个人博客已从单纯的信息发布平台逐步发展为集创作、管理、互动与知识分享于一体的综合性应用。然而，传统个人博客系统在内容创作流程、智能化辅助以及即时交互体验等方面仍存在一定不足，创作者往往需要借助外部工具完成写作与润色，读者在阅读过程中也缺少针对文章内容的快速问答与深度理解渠道。基于此，本文设计并实现了一套基于 Next.js 的 AI 辅助个人博客系统，围绕“创作一站式、辅助智能化、互动即时化”的目标，提升博客内容生产效率与用户阅读体验。

该系统采用 Next.js 作为核心开发框架，结合 Prisma 与 PostgreSQL 完成数据建模与持久化存储，并集成 DeepSeek 等大模型接口实现 AI 创作辅助与问答能力。系统主要包含一站式博客创作与管理、用户管理、AI 创作辅助、AI 问答悬浮球、评论互动及通知管理等功能模块，支持 Markdown 文章编辑、文件导入、草稿保存、发布撤回、分类标签管理、文章内容问答以及历史记录保存等操作。实践表明，该系统能够有效简化博客创作流程，增强内容表达与知识解读能力，为个人创作者与读者提供更加高效、智能和便捷的博客使用体验。

关键词：Next.js；个人博客；人工智能；Markdown；Prisma；PostgreSQL
